# Tata Landing Page

Static landing page for the Tata product.

## Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Project structure

```
.
├── index.html
├── css/
│   ├── styles.css
│   └── responsive.css
├── js/
│   ├── main.js
│   └── i18n.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── logo/
└── README.md
```

## Requirements covered by the scaffold

- Responsive layout foundation
- Accessibility-ready semantic HTML
- i18n foundation with `en_US` as default and `es_419`
- SEO metadata foundation
- Vanilla HTML, CSS and JavaScript only

## Branching

- `main`: stable baseline
- `develop`: active development
